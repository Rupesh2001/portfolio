# Rupesh Mahat QA Portfolio

This portfolio presents work as a QA test run and is designed for Netlify deployment.

## Local run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Netlify deploy

```bash
git init && git add . && git commit -m "Initial portfolio"
# create GitHub repo and push
# Netlify dashboard > Add new site > Import from Git
```

## Editing project data

Update the project and profile content in:

- `src/data/profile.ts`
- `src/data/projects.ts`
